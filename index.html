Projects

FitQuest

FitQuest is a stat-based fitness tracking app that gamifies workouts. Users can log their activities, earn rewards, and track their progress using customizable stats such as Agility, Strength, Stamina, Dexterity, and Consistency. The app is built for Android and leverages Firebase for real-time data management, with a sleek and user-friendly UI designed using Jetpack Compose.

Used Car Data Analysis Project

I created this project to apply my SQL skills and learn MySQL for data analysis. Importing the dataset allowed me to explore pricing trends, transmission types, and fuel availability—topics that connect with my passion for cars. This experience strengthened my SQL abilities and deepened my understanding of real-world data analysis.

Movie Data Analysis Project

I worked on a movie data analysis project to explore patterns in film genres, audience ratings, and box office performance. I used SQL extensively, including Common Table Expressions (CTEs), to clean, structure, and analyze the data efficiently. Through this project, I identified key trends and correlations, and created visual summaries to highlight how factors like genre and release year influence a movie's success.
